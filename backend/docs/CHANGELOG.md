# API Changelog

All notable changes to the Nearby Locator API will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-07-09

### Added
- Initial release of the OpenAPI 3.1 specification for `/api-docs/v1`.
- Fully documented Authentication, Authorization, Users, and Admin endpoints.
- Introduced standard error mappings and telemetry headers (`X-Request-ID`).
