# Nearby Locator

## Overview
An intelligent, location-aware platform utilizing PostgreSQL and PostGIS to securely serve geospatial discovery features, dynamic map clustering, and community-driven moderation.

## Key Features
- **Geospatial Intelligence**: PostGIS-powered querying, yielding dynamic cluster grids for mapping interfaces.
- **Robust Security**: Rate limiting, brute-force mitigation via Redis, and comprehensive audit logging.
- **Admin Control Plane**: Manage moderation appeals, quarantine zones, and telemetry.
- **Notification System**: Webhook integrations, user preference targeting, and dead-letter queues.
